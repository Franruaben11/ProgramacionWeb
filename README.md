## Cómo ejecutar el proyecto

Para asegurarte de tener la última versión e iniciar el servidor local, seguí estos pasos:

1. **Descargá el proyecto:** 
   Cloná el repositorio en tu computadora ejecutando:
   ```git clone https://github.com/Franruaben11/ProgramacionWeb.git```

2. **Actualizá el código local:** 
   Traé los últimos cambios del repositorio ejecutando:
   ```git pull```

3. **Iniciá el servidor:**
  Ubicado en la carpeta raíz del proyecto, levantá la aplicación con Go:
  ```go run .```

4. **Accedé a la aplicación:**
Abrí tu navegador web e ingresá a ```http://localhost:8080```.
